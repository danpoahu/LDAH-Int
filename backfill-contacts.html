Backfill Contacts from Signups

One-time migration: link signups to contact records (idempotent, safe to re-run)

Admin Login Required


What This Does

Scans every signup across events and recurringEvents and links each one to a contact record:

1. If the signup already has a linkedContactId, it is skipped.
2. If a matching contact exists (by email or phone), the signup is linked to it.
3. If no match, a new contact is created and linked.
4. The parent event's title is written as eventTitle on the signup.

This is idempotent. Running it again will only process signups that were missed or added since the last run.
